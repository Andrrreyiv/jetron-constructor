## Инструменты

- **Edit/Write иногда падают `Not logged in`** → обход: node-скрипт точечных замен через Bash
  (однострочные якоря, `includes`-проверка, `process.exit(1)` при непопадании). ⚠️ У `deploy/*.php`
  в дереве **CRLF**: нормализовать перед поиском якоря и вернуть перед записью. ⚠️ Большой heredoc
  в Bash рвётся на спецсимволах — надёжнее Write в scratchpad + короткий node-скрипт вставки.
- **Windows autocrlf:** сверять деплой с HEAD-блобами (`git show HEAD:путь | sha256sum`), не с
  рабочим деревом. SHA-256 надёжнее GitHub API (60 запросов/час, raw-CDN отстаёт на минуты).
- **Кириллица в git:** `ls-files` отдаёт её экранированной (`\320\261…`) и `xargs rm` молча
  не удаляет ничего. Всегда `git -c core.quotepath=false`.
- **Кириллица в URL при проверке демо:** список читать через `tr -d '\r'` и percent-кодировать,
  иначе curl ответит «Malformed input to a URL function» и покажет ложные битые ссылки.
- **Фильтр вывода режет значения по виду и по имени ключа** (хэши, `hasNewToken`, `href` с query).
  Лечение: сравнивать ВНУТРИ страницы и возвращать булево под нейтральным именем.
- **`mcp__claude-in-chrome__javascript_tool`** требует top-level `await` (асинхронная IIFE вернёт
  пустой объект); в `mcp__Claude_Browser__javascript_tool` наоборот — оборачивать в `new Promise`.
- **Вкладка в фоне / панель браузера:** `visibilityState: "hidden"` → `requestAnimationFrame` не
  идёт, `ResizeObserver` молчит, `getBoundingClientRect` нули, холст Fabric пустой. Артефакт среды,
  не баг: проверять через объекты и таймеры либо форсировать `canvas.renderAll()`.
- **`app.views` это Map:** `Object.keys(app.views)` всегда `[]`, мерить `.size` и `[...keys()]`.
- **Claude Preview MCP:** `localhost` в его браузере не открывается, **брать `127.0.0.1`**.
  ⚠️ Он читает `C:\Projects\.claude\launch.json` (РОДИТЕЛЬСКИЙ), а не проектный — добавлять
  конфигурацию туда. Порт 8777 держит осиротевший процесс, для превью заведена вторая
  конфигурация `jetron-preview` на 8778. `preview_screenshot` подвисает по 30 с при живом
  `preview_eval`.
- **Смена формы в превью:** метода `setForm` нет. `app.formId = '<id>'; await app.buildViews();
  await app.renderAll();`. `setOptData(opt, patch)` принимает ОБЪЕКТ опции из
  `availableOptions()`, а не строку id — со строкой молча пишет в `optCache[undefined]`.
- **Расшифровка голосовых:** `PYTHONIOENCODING=utf-8 python docs/transcribe_one.py <файл>` либо
  `faster-whisper` (small, ru). Звук из mp4 — ffmpeg из
  `python -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())"`, отдельного ffmpeg
  на машине НЕТ. ⚠️ Вывод в файл: кириллица в консоли бьётся. ⚠️ Кадры видео брать в ПОЛНОМ
  разрешении (`-ss N -frames:v 1`), даунскейл делает интерфейс нечитаемым.
- **tdd-guard:** stub-first (пустой export → красный тест → реализация); слеп к голому `node --test`.
- **`serve` роняет query на `/index.html`** — `?zones=edit` цеплять к корню:
  `http://localhost:8777/?zones=edit`.

## Замеры, которые переиспользуем (не переделывать)

**Холст в конфиге:** `mock-config.json` → `canvas { width: 900, height: 1200,
displayWidth: 450 }`. ⚠️ Число 1200 здесь — только эталон для долей зон и стартовое значение:
реальную высоту `setBackground` подгоняет под картинку (см. «Контракт кадра» в `CLAUDE.md`).
Клиент на слух называл «900 на 1000» — ошибся.

**Кадр композитный:** слева перёд, справа зад, белый фон, все 45 исходников квадратные.
**Пропорция самой формы 0.48-0.62 (в среднем 0.58), пары «перёд + зад» 1.05-1.34.**
Отсюда всё остальное: упирается ШИРИНА, высоту рамки задаёт зазор поставщика между видами.
После перегона 30.08 заполнение 56-71 % высоты, нижний зазор 38..125 px (было 130..310),
вес файла 25..132 КБ.

**Размерные сетки.** У каждой модели своя таблица в ACF на таксономии `pa_model`
(term_id: Champion 54, New 59, Rich 42, Space 43, Star 44, Winner 45, Волна 70).
Подполя: `sizes_adult` — `size` (объект term, брать `$v->name`), `size_rus`, `height`,
`shirt_height`, `shirt_width`; `sizes_child` — `size`, `height`, `age`, `shirt_height`,
`shirt_width`, `shorts_height`, `shorts_width`. В конструктор отдаём три столбца.
ACF Pro 6.4.1, активен. ⚠️ В карточках товаров атрибут «Размер» это **БИРОЧНАЯ** шкала
(S…5XL), а российский размер и рост берутся из таблицы по букве — это корень старой путаницы.
