## Инструменты

- **Edit/Write иногда падают `Not logged in`** → обход: node-скрипт точечных замен через Bash
  (однострочные якоря, `includes`-проверка, `process.exit(1)` при непопадании). ⚠️ У `deploy/*.php`
  в дереве **CRLF**: нормализовать перед поиском якоря и вернуть перед записью. ⚠️ Большой heredoc
  в Bash рвётся на спецсимволах — надёжнее Write в scratchpad + короткий node-скрипт вставки.
- **Windows autocrlf:** сверять деплой с HEAD-блобами (`git show HEAD:путь | sha256sum`), не с
  рабочим деревом. SHA-256 надёжнее GitHub API (60 запросов/час, raw-CDN отстаёт на минуты).
- **Кириллица в git:** `ls-files` отдаёт её экранированной (`\320\261…`) и `xargs rm` молча
  не удаляет ничего. Всегда `git -c core.quotepath=false`.
- **Кириллица в URL при проверке демо:** список читать через `tr -d '\r'` и percent-кодировать,
  иначе curl ответит «Malformed input to a URL function» и покажет ложные битые ссылки.
- **Фильтр вывода режет значения по виду и по имени ключа** (хэши, `hasNewToken`, `href` с query).
  Лечение: сравнивать ВНУТРИ страницы и возвращать булево под нейтральным именем.
- **`mcp__claude-in-chrome__javascript_tool`** требует top-level `await` (асинхронная IIFE вернёт
  пустой объект); в `mcp__Claude_Browser__javascript_tool` наоборот — оборачивать в `new Promise`.
- **Вкладка в фоне / панель браузера:** `visibilityState: "hidden"` → `requestAnimationFrame` не
  идёт, `ResizeObserver` молчит, `getBoundingClientRect` нули, холст Fabric пустой. Артефакт среды,
  не баг: проверять через объекты и таймеры либо форсировать `canvas.renderAll()`.
- **`app.views` это Map:** `Object.keys(app.views)` всегда `[]`, мерить `.size` и `[...keys()]`.
- **Claude Preview MCP:** `localhost` в его браузере не открывается, **брать `127.0.0.1`**.
  ⚠️ Он читает `C:\Projects\.claude\launch.json` (РОДИТЕЛЬСКИЙ), а не проектный — добавлять
  конфигурацию туда. Порт 8777 держит осиротевший процесс, для превью заведена вторая
  конфигурация `jetron-preview` на 8778. `preview_screenshot` подвисает по 30 с при живом
  `preview_eval`.
- **Смена формы в превью:** метода `setForm` нет. `app.formId = '<id>'; await app.buildViews();
  await app.renderAll();`. `setOptData(opt, patch)` принимает ОБЪЕКТ опции из
  `availableOptions()`, а не строку id — со строкой молча пишет в `optCache[undefined]`.
- **Расшифровка голосовых:** `PYTHONIOENCODING=utf-8 python docs/transcribe_one.py <файл>` либо
  `faster-whisper` (small, ru). Звук из mp4 — ffmpeg из
  `python -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())"`, отдельного ffmpeg
  на машине НЕТ. ⚠️ Вывод в файл: кириллица в консоли бьётся. ⚠️ Кадры видео брать в ПОЛНОМ
  разрешении (`-ss N -frames:v 1`), даунскейл делает интерфейс нечитаемым.
- **tdd-guard:** stub-first (пустой export → красный тест → реализация); слеп к голому `node --test`.
- **`serve` роняет query на `/index.html`** — `?zones=edit` цеплять к корню:
  `http://localhost:8777/?zones=edit`.

## 01.09 — Preview MCP и Claude in Chrome отвалились оба, чем мерить вместо них

Вкладка Preview MCP встала намертво на `chrome-error://chromewebdata/` после попытки уйти
на `https://andrrreyiv.github.io/...` (демо из этого браузера не открывается). После этого
`location.replace`, `location.assign`, `history.go(-1)`, `preview_stop` + `preview_start`
и даже новый `serverId` возвращают ту же ошибочную страницу: вкладка не переиспользуется.
`preview_screenshot` при этом отдаёт пустой белый кадр, а `preview_snapshot` — голый
`RootWebArea`. Claude in Chrome в тот же момент отвечал «extension isn't reachable»,
chrome-devtools MCP в сессии не поднят.

**Обход, которым сделаны все замеры 01.09** — headless Chromium напрямую, минуя MCP:

```js
import { chromium } from 'file:///C:/Users/Андрей/AppData/Roaming/npm/node_modules/@playwright/mcp/node_modules/playwright/index.mjs';
const browser = await chromium.launch({ headless: true });
const page = await browser.newPage({ viewport: { width: 1366, height: 768 }, deviceScaleFactor: 1 });
await page.goto('http://localhost:8778/', { waitUntil: 'networkidle' });
await page.waitForFunction(() => window.__jetronApp && document.querySelectorAll('.model-card').length > 0);
```

Пакет `playwright` глобально НЕ установлен, он лежит внутри `@playwright/mcp`; браузеры
уже скачаны в `~/AppData/Local/ms-playwright`. Скрипт класть во временную папку и удалять
после замера, в репозиторий не коммитить.

⚠️ Мерить приходится на localhost, поэтому ДО замеров сверять sha256 живого демо с
`git show origin/main:<файл>` и убеждаться, что рабочее дерево чистое и равно `origin/main` —
иначе замер описывает не то, что видит клиент.

⚠️ Селекторы, на которых легко промахнуться: палитра ЦВЕТА ФОРМЫ — это `#colorpick
.color-palette .pcolor` (15 штук), а `.color-sw` внутри карточки «Фамилия и номер» это
7 цветов ТЕКСТА, другое. Горизонтально прокручивается `.model-carousel` ВНУТРИ `#modelpick`,
сам `#modelpick` имеет `overflow-x: visible` и всегда показывает `scrollLeft = 0`.
Строки образцов считать кластеризацией `top` с допуском в половину высоты: у активного
свотча рамка даёт разброс в 2 px, и наивный `new Set(tops)` рисует «две строки» на пустом месте.

⚠️ **Ловушка волны 4, самая дорогая из всех: узкий viewport — это НЕ телефон.**
`newPage({ viewport: { width: 360 } })` без `hasTouch`/`isMobile` оставляет `pointer: fine`,
и весь блок `@media (pointer: coarse)` выключен. В нём у нас живут разные размеры: пилюля
`.line-badge-pill` получает `padding 7px 8px` + `min-height: 36px` вместо `padding 5px 11px`,
и ряд становится **36 px вместо 28.3**. Замер без касания описывает пользователя узкого ОКНА
десктопного браузера, а не покупателя с телефоном. Практический итог 02.09: без касания зазор
на 412 читался как 15.2 px, с касанием — **7**; зато «перенос текста на две строки при 360»
существовал ТОЛЬКО без касания. Оба вывода были наполовину ложными.
Правильный запуск:
```js
const page = await browser.newPage({
  viewport: { width: 412, height: 900 }, deviceScaleFactor: 2,
  hasTouch: true, isMobile: true,          // ← без этих двух строк меряется ПК
});
```
⚠️ Если правка касается только телефона — класть её в мобильный медиазапрос
(`max-width: 560px`), тогда критерий приёмки 1366×768 она не заденет и перемерять восемь
линеек не придётся. Но перемерять всё равно дешевле, чем гадать: `.localdev/v.mjs`, минута.

⚠️ **Две ловушки замера третьей волны, обе уже сработали — не повторять.**
**(1)** «Зазор до правого края» мерить до края РЯДА, а не до края экрана: до экрана всегда
12 px, это отступ страницы, и он ошибочно читается как регресс. До края ряда — **0**.
**(2)** Прокрутку палитры мерить на НАСТОЯЩЕМ скроллере — ближайшем предке `.pcolor`,
у которого `scrollWidth > clientWidth`. Взять `.colorpick` мало: он не прокручивается,
даёт `0 → 0` и создаёт видимость успеха при ЛЮБОМ состоянии кода. Тем же способом врал
замер карусели (у дальнего цвета всего одна модель — мерить на цвете по умолчанию).
